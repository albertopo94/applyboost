# Spec: why-it-works-explanation

## Requirements

1. **Detailed Explanations**: The LLM MUST generate technical rationales for both the optimized CV and the Cover Letter.
2. **Standard Format**: Explanations SHOULD cover:
   - Key requirements addressed.
   - Best utilized parts of the source CV.
   - Tone appropriateness.
3. **UI Display**: The explanations MUST be displayed prominently below the main editor area to educate and reassure the user.
4. **Visibility**:
   - The CV explanation is always visible.
   - The Cover Letter explanation is only visible if a Cover Letter was generated.

## Scenarios

### Scenario 1: Displaying both explanations
**Given** a successful generation with both CV and Cover Letter
**When** the user is in the Editor view
**Then** two distinct sections titled "Por qué este CV funciona" and "Por qué esta carta funciona" MUST appear below the editor.

### Scenario 2: Education Content
**Given** the explanations generated by the LLM
**When** the user reads them
**Then** they MUST contain specific references to the job requirements (e.g., "Cubre el requisito de Python mediante tu experiencia en ETECSA").

### Scenario 3: Responsive Layout
**Given** a mobile device
**When** viewing the explanations
**Then** they SHOULD stack vertically instead of being in two columns.
